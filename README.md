# EVENTLOGS

An automated register of accidents, disasters, incidents, and disease
outbreaks reported by public news sources worldwide extracted, deduplicated,
and published as flat, machine-readable records with no personal information.

Each record is a single factual line: country, cause, location and source.
Generated by a self-hosted collection pipeline that polls global news and
disaster-monitoring feeds around the clock.
